1. System Overview

bisik by rygh is an automated captioning and kinetic typography extension for Adobe Premiere Pro. Unlike cloud-reliant captioning plugins, it executes local sample-accurate speech recognition with zero subscription fees, private offline audio inference, and direct Motion Graphics Template (MOGRT) timeline injection with dynamic expression-driven styling.

🚀 Zero Model Reload Loop

Consolidates multi-clip timelines into a single continuous master WAV with exact silence bridges, transcribing entire sequences in one pass.

📐 Mathematical Precision

Locked to Adobe's universal tick rate (254,016,000,000 ticks/sec) and sequence frame boundaries, eliminating 1-frame gaps.

🎨 Adobe Spectrum Compliant

Automatically synchronizes with Premiere Pro's 4 brightness themes with high-contrast accessible typography.

Three-Tier Execution Layer

  • Frontend Tier (Chromium / CEF): Pure HTML5/CSS3 interface matching Adobe Spectrum design tokens, with live CTI playhead polling (80 ms) suspended during inactivity.
  • Node.js Background Tier: Activated via --enable-nodejs and --mixed-context in CSXS/manifest.xml. Handles subprocess spawning, cross-platform binary paths, and taskkill process tree disposal.
  • ExtendScript Host Tier (ES3): Controls Premiere timeline objects, sequence tracks, MOGRT import, and speed-remap scaling. Features secure RFC 4627 JSON parsing.

3. Audio & Whisper AI Pipeline

To eliminate audio drift and model load thrashing, the pipeline executes in 4 distinct phases:

  1. Multi-Clip WAV Extraction: Converts audio to 16 kHz 16-bit mono PCM via FFmpeg with output seeking (-ss positioned after -i) for sample accuracy.
  2. Silence Gap Bridging: Fills inter-clip timeline gaps with exact duration synthesized silence using anullsrc=r=16000:cl=mono.
  3. Audio Consolidation: Merges all segments using FFmpeg's concat demuxer into a single master_consolidated.wav.
  4. Single-Pass Whisper Inference: Whisper AI loads the 3 GB model once, transcribing the entire master audio file with word-level timestamps.
whisper-cli Execution Flags 
whisper-cli \
  -t 6 \
  -m ~/.whisper-models/ggml-large-v3.bin \
  -f master_consolidated.wav \
  -l id \
  -oj \
  -of transcription_master \
  -sow \
  -ml 1 \
  --entropy-thold 2.4 \
  --logprob-thold -1.0 \
  --no-fallback \
  --prompt "Indonesian conversational speech with English technical video editing terms."
Anti-Hallucination Guardrails: Flags --entropy-thold 2.4 and --logprob-thold -1.0 terminate decoding when acoustic confidence is low, and --no-fallback stops temperature looping during background music and silence.

4. Subtitle Chunker & Quality Control (QC)

The subtitle chunking algorithm enforces strict multi-dimensional broadcast constraints:

Constraint Standard Limit Enforcement Behavior
CPL (Characters Per Line) 38 chars max Breaks chunk before overflowing; splits dual-line mode symmetrically.
Max Duration 6.0 seconds max Prevents single subtitle blocks from lingering across scene changes.
Min Duration 0.83 seconds min Guarantees human readability (~20 frames at 24 fps) without flashing.
CPS (Reading Speed) 20.0 chars/sec max Flags warning pill in Word Editor when text pace is too fast for viewer.
Speech Pause Gap ≥ 0.8 seconds Automatically breaks subtitle card on natural pauses.

5. Timecode & Ticks Mathematics

Premiere Pro calculates all timeline positions in universal ticks:

ExtendScript Frame Boundary Quantization
var ticksPerSecond = 254016000000;
var ticksPerFrame = parseFloat(seq.timebase) || (ticksPerSecond / 25);

function quantizeTicksToFrame(seconds) {
    var rawTicks = seconds * ticksPerSecond;
    var frameIndex = Math.round(rawTicks / ticksPerFrame);
    return Math.round(frameIndex * ticksPerFrame);
}

// In loop:
var startTicks = quantizeTicksToFrame(seg.start).toString();
var endTicks = quantizeTicksToFrame(seg.end).toString();
